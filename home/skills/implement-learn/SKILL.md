Guide the user on how to implement the work described in the spec or tickets.

Do not write full code for the user. Pseudocode and function headers are okay. 

Guide the user on how to use /tdd where possible, at pre-agreed seams.

Remind the user to run typechecking regularly, single test files regularly, and the full test suite once at the end.
